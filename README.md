# 🌤 晴屿 · 智能天气桌面应用（Smart Weather）

一个开箱即用的**独立桌面天气应用**：双击即运行，自动定位当前位置。界面由 pywebview
渲染为精致独立窗口（无浏览器工具栏、无 Web 服务），以"天空切片"为设计主题：
动态星尘背景、毛玻璃卡片、晚霞概率环形仪表、**SVG 日出日落方位地图**、温度趋势折线、全国霞光地图。

> 兼容 **Python 3.9+**；数据源 Open-Meteo（免费、无 API Key、覆盖全球）+ 中国天气网官方实况/预报
> + 中央气象台在线预警与台风路径（均免费、无需 Key）。
>
> 🔗 GitHub：https://github.com/wenki2005/qingyu-smart-weather

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行（两种方式任选）

```bash
python weather_desktop.py              # 自动定位 + 桌面窗口
python weather_desktop.py --city 上海   # 指定城市启动
python weather_desktop.py --cli        # 无界面：打印一次天气报告
```

或直接双击 [启动天气桌面版.bat]（自动探测 Python 并补齐依赖）。

> 提示：需要 Python 3.9+ 且带 tkinter（python.org 官方安装包或 Visual Studio 随附 Python 均自带）。
> 若环境缺 tkinter，程序会给出明确中文提示而不会闪退。

### 3. 配置（可选）

复制 `.env.example` 为 `.env`，可按需调整默认城市、经纬度、时区与预警阈值。

### 赏月指南模型

```
Score = 0.55 × 照明度 + 0.35 × 夜空通透度 + 0.10 × 降水抑制
```

月相采用 synodic 近似算法（以 2000-01-06 新月为基准，周期 29.5306 天），
照明度不足 8% 或夜间云量 ≥85% 时强制压低指数。最佳赏月时段由「约估月出时间」推导。

### 生活指数

基于 Open-Meteo 已有数据计算：穿衣（气温）、带伞（降水）、洗车（今明降水）、
防晒（UV）、运动（风/气温/降水）、晾晒（降水/湿度）、感冒（温差）。

### 预警规则

规则引擎基于 Open-Meteo 预报数据分级检测，全部免费无需 Key：

| 预警 | 触发条件 | 等级 |
| --- | --- | --- |
| 台风「XX」影响提醒 | 距中央气象台台风路径 ≤700 km（按真实台风判定） | 蓝~红 |
| 狂风 | 持续风速 ≥ 32.7 m/s（12 级） | 红色 |
| 强风 | 持续风速 ≥ 24.5 m/s（10 级） | 橙色 |
| 强阵风 | 阵风 ≥ 32.7 m/s | 橙色 |
| 大风 | 持续风速 ≥ 17.2 m/s（8 级） | 黄色 |
| 冰雹（大） | 天气码 99（强雷暴伴大冰雹） | 红色 |
| 冰雹（小） | 天气码 96（雷暴伴冰雹） | 橙色 |
| 高温 / 低温 / 强降雨 / 大雾 / 雷暴 / 降雪 / 强紫外线 | 见 `app/config.py` 阈值 | 黄/橙 |

> 规则引擎的普通大风**不会**标成「台风」——只有检测到真实台风路径（typhoon.nmc.cn）且
> 处于影响半径内才给出台风预警。中央气象台官方预警联网获取（按省/市过滤，点击可跳转详情页）；
> 配置和风天气 API Key 后可叠加和风官方预警。

### 晚霞概率模型

```
P = 0.45 × Cloud(云量) + 0.35 × Precip(降水) + 0.10 × Visibility + 0.10 × Humidity
```

云量 35% 附近最优（有云反射、太少无云、太多遮挡）；降水概率 ≥70% 视为"基本没戏"；
雷暴/大雾封顶 25 分。≥75 高 / ≥50 中 / <50 低。
